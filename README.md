# 🏙️ NagarSetu

### A Civic Resolution Network

NagarSetu is a civic resolution platform that connects citizens with authorities to help identify, report, and resolve local community problems.

Citizens can report issues in their area, and NagarSetu helps bring these problems to the attention of the appropriate authorities so that action can be taken.

## 🚨 How NagarSetu Works

1. **Report a Problem**  
   Citizens report civic issues such as damaged roads, garbage, broken streetlights, water problems, and other local concerns.

2. **Locate the Issue**  
   Reported problems are displayed on an interactive map according to their location.

3. **Severity Tracking**  
   Issues are categorized based on severity:
   - 🔴 Severe
   - 🟡 Mild

4. **Authority Action**  
   Reported issues can be addressed to the relevant authorities for necessary action.

5. **Resolution Tracking**  
   Citizens can see whether an issue is:
   - 🔴 Reported
   - 🟡 In Progress
   - 🟢 Solved

## 🗺️ Key Features

- 📍 Location-based civic issue reporting
- 🗺️ Interactive issue map
- 🚨 Severity classification
- 📊 Issue status tracking
- 🏛️ Authority-focused reporting
- 🤝 Citizen participation in local governance
- 🔄 Transparent resolution tracking

Our mission is to create a stronger connection between citizens and local authorities by making civic problems easier to report, track, and resolve.
